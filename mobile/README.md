# Дневник тренировок — мобильное приложение

React Native + Expo. Своего бэкенда и базы у приложения нет: оно отправляет запросы
к серверу Flask из папки `backend` (тот же сервер, что и у сайта).

## Как устроено

```
app/                 экраны: один файл = один экран (как страницы сайта)
  login.js           вход и регистрация
  (tabs)/index.js    главная: календарь, тренировки дня, ближайшие
  (tabs)/create.js   новая тренировка
  (tabs)/profile.js  профиль и выход
  workout/[id].js    тренировка: просмотр, «Выполнено», удаление
  workout-form.js    изменение тренировки
components/          общие части экранов: календарь, форма тренировки, кнопки, иконки
lib/api.js           запросы к бэкенду и хранение токена входа
lib/dates.js         даты и подписи
lib/theme.js         цвета и шрифты
package.json         библиотеки приложения (React Native, Expo)
```

Вход: после входа сервер присылает токен. Приложение хранит его в защищённом хранилище телефона
(SecureStore) и отправляет с каждым запросом в заголовке `Authorization: Bearer <токен>`.

Адрес бэкенда виден на экране входа (поле «Адрес сервера»). В другой Wi-Fi сети у компьютера другой адрес —
узнать его можно командой `ipconfig` (строка IPv4 у беспроводной сети), в поле вводится `http://<адрес>:3000`.

## Запуск

1. Запустите бэкенд (см. `backend/README.md`).
2. В этой папке (`npm install` — один раз, чтобы установить библиотеки):
   ```
   npm install
   npm start
   ```
3. Отсканируйте QR-код приложением Expo Go (телефон и компьютер в одной Wi-Fi сети)
   или нажмите `w`, чтобы открыть приложение в браузере (http://localhost:8081).

## Сборка APK для Android

Сборка идёт в облаке Expo (EAS Build), нужен бесплатный аккаунт на expo.dev.
Настройки сборки — `eas.json` (профиль `apk`, адрес сервера по умолчанию) и `app.json`
(имя пакета `com.fitdiary.app`, разрешение обычного `http` — `usesCleartextTraffic`).

```
npx eas-cli login
npx eas-cli build -p android --profile apk
```

Через 10–30 минут появится ссылка на APK-файл: его скачивают на Android-телефон и устанавливают.
